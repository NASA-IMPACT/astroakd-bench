# AstroAKD-Bench 0.2.0 — SYNTHETIC_QUERY_GENERATION

An additive update to the formally accepted AstroAKD-Bench 0.1.0 foundation.
This package adds a deterministic, signature-aware **candidate** generator.
It does not call live archive queries or create validated reference answers.

See `INSTALL_ASTROAKD_BENCH_0_2_0.md` and
`docs/benchmark/synthetic_query_generation.md`.
